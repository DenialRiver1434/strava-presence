# Strava Presence

A small personal Windows tool that shows my most recent sports activity, and a
live card while an activity is in progress, as Discord Rich Presence.

- It runs only on my own computer, for my own accounts.
- Activity summaries come from the Garmin Connect Personal API.
- To notice a live activity it looks for the Garmin LiveTrack email in my own
  Gmail mailbox (read-only access).
- It talks to the local Discord desktop client to set the presence.

This project is not affiliated with Strava, Garmin, Google or Discord.

See [PRIVACY.md](PRIVACY.md) for how data is handled.
