# Privacy Policy

Strava Presence is a personal tool used by a single person on their own computer.

## What it accesses

- **Gmail (read-only):** it searches the user's own mailbox for the Garmin
  LiveTrack notification email and reads that message to find the LiveTrack
  session link. No other mail is read, and nothing in the mailbox is changed.
- **Garmin:** the user's own activity summaries and the user's own LiveTrack
  session data.

## What it does with the data

- Data is processed in memory on the user's computer.
- The only thing shown to others is the Discord Rich Presence card (activity
  name, distance, time and similar summary figures).
- Nothing is sent to the author or to any other third party. There are no
  analytics, no advertising and no server component.
- Sign-in tokens are stored in a local file on the user's computer and can be
  removed by deleting that file or by revoking access in the Google account
  settings.
